Optical Propagation Methods

Here are some useful optical propagation methods.

OpticalPropagation.angularspectrum — Function
angularspectrum(Uin, d, λ, lx, ly)

calculate the propagation light field based on the angular spectrum.

The input and output use the same uniformly sampled periodic window. Spatial frequencies follow FFT order for both odd and even sample counts. Nonpropagating components ((λ*fx)^2 + (λ*fy)^2 > 1) are suppressed for nonzero distances, including backward propagation. Zero distance returns an independent complex copy. d must be finite; λ, lx and ly must be finite and positive.

Arguments

  • Uin::AbstractArray{<:Number,2}: Complex array of input complex amplitude.
  • d::Real: Distance to propagate in metres.
  • λ::Real: Wavelength of light to propagate.
  • lx::Real: The physical size of the input data along the x-axis.
  • ly::Real: The physical size of the input data along the y-axis.

Returns

  • ::Array{<:Number,2}: Complex amplitude data after propagation.

OpticalPropagation.fresnel1 — Function
fresnel1(Uin, d, λ, lx, ly)

calculate the propagation light field based on the Fresnel diffraction with single Fourier transform.

Input coordinates are x[i] = -lx/2 + (i-1)*lx/n, and similarly for y. The output follows the same half-open convention with positive widths lxo = λ*abs(d)/(lx/n) and lyo = λ*abs(d)/(ly/m). Both quadratic phases and the phase from the coordinate origins are included, for odd/even and singleton dimensions. A negative distance uses an unnormalised backward FFT and retains increasing output coordinates. Zero distance returns a copy with the input widths. d must be finite; wavelength and input widths must be finite and positive.

Arguments

  • Uin::AbstractArray{<:Number,2}: Complex array of input complex amplitude.
  • d::Real: Distance to propagate in metres.
  • λ::Real: Wavelength of light to propagate.
  • lx::Real: The physical size of the input data along the x-axis.
  • ly::Real: The physical size of the input data along the y-axis.

Returns

(Uout, (lxo, lyo))
  • Uout::Array{<:Number,2}: Complex amplitude data after propagation.
  • lxo::Real: The physical size of the diffraction data along the x-axis.
  • lyo::Real: The physical size of the diffraction data along the y-axis.

OpticalPropagation.fresnelkirchhoff — Function
fresnelkirchhoff(Uin, d, λ, lx, ly; radius=Inf)

Propagate a sampled scalar field with a Fresnel–Kirchhoff zone-mask convolution, following Hudson's spherical-reference-surface approximation [1]. All lengths in this array interface are in metres. The result is a Matrix{ComplexF64} with the same number of samples as Uin; input samples outside the array are zero.

d is a finite, nonnegative axial distance; λ, lx, and ly are finite and positive. lx and ly are the input widths along the first and second array dimensions, with sample pitches lx/size(Uin, 1) and ly/size(Uin, 2). Zero distance returns an independent complex copy of the input.

By default, the input and output are parallel planes with the same physical size, and normally incident illumination is assumed. The impulse response is exp(2πim*s/λ) * (1 + d/s) / (2im*λ*s), where s = sqrt(d^2 + x^2 + y^2). The FFTs are padded to compute a linear convolution without periodic wraparound.

A finite, nonzero radius specifies a signed input reference-sphere radius: positive for a diverging wave and negative for a converging wave. The output sphere is concentric, with signed radius radius + d. Its projected physical size is (1 + d/radius) .* (lx, ly). Propagation to or through the common centre is unsupported. The data give the actual complex amplitude on the input cap, including its reference-wave amplitude and phase. The returned data similarly give the actual amplitude on the output cap.

The grid is projected perpendicularly from the tangent plane onto the sphere, with coordinates x[i] = -lx/2 + (i-1)*lx/n and similarly for y, as in the light-field plotting recipe. The surface-area Jacobian is included. Both the input and the entire displacement grid must fit inside a hemisphere. Translation on this grid approximates rotation on the sphere, so use caps small compared with abs(radius). The oscillatory zone mask must also be adequately sampled; zero padding does not correct undersampling or aperture truncation.

[1] J. A. Hudson, "Fresnel-Kirchhoff diffraction in optical systems: an approximate computational algorithm," Applied Optics 23, 2292–2295 (1984), https://doi.org/10.1364/AO.23.002292, Eqs. (1)–(5).

source
fresnelkirchhoff(Uin::MonoLightField2D, d::Unitful.Length;
                 radius::Unitful.Length=Inf*u"m") -> MonoLightField2D

Propagate a monochromatic light field with fresnelkirchhoff. A finite signed radius selects a spherical reference surface and scales the output physical size by 1 + d/radius. The wavelength is preserved. The planar mode preserves the window centre. Finite-radius propagation currently requires a zero-centred window; support for off-axis spherical caps is deferred.

fresnelkirchhoff(d; kwargs...)

Return a propagation functor with fixed distance and optional reference radius. For example, fresnelkirchhoff(1u"cm")(field) propagates a light field by 1 cm.

OpticalPropagation.rayleighsommerfeld — Function
rayleighsommerfeld(Uin, d, λ, lx, ly; quadrature=:rectangle,
                  output_size=(lx, ly), output_samples=size(Uin), padding=1)

Evaluate the first Rayleigh–Sommerfeld diffraction integral between parallel planes using FFT direct integration (FFT-DI) [1] or Nascov and Logofătu's scaled convolution [2]. All lengths in this matrix interface are in metres. The output is a Matrix{ComplexF64}. The input is zero outside its finite window.

output_size and output_samples independently specify the output window widths and positive integer sample counts. Each defaults to the corresponding input value. The pitches are output_size ./ output_samples. Both windows are centred at zero, with half-open coordinates x[i] = -Lx/2 + (i-1)*Lx/Nx. Equal input and output grids use ordinary FFT-DI; other grids use scaled convolution with chirp-based scaled Fourier transforms [2, Eqs. (14)–(22) and Appendix A], generalized to rectangular arrays and unequal sample counts.

For d > 0, the full impulse response is h(x,y) = d*exp(2πim*r/λ)/(2π*r^2) * (1/r - 2πim/λ), where r = sqrt(x^2 + y^2 + d^2). Both the spherical phase and near-field 1/r term are retained. Zero-padded FFTs evaluate a linear convolution without periodic wraparound. Sampling must resolve the input and the oscillatory kernel; padding alone cannot correct undersampling, especially near d = 0.

quadrature=:rectangle assigns every input sample the area Δx*Δy, consistent with the half-open physical windows used by MonoLightField2D. quadrature=:simpson uses the tensor product of Simpson's weights [1,4,2,…,4,1]/3 [1, Eqs. (17)–(20)]. It requires odd sample counts of at least three on both axes and integrates only between the first and last sample coordinates, spanning (N-1)*Δ rather than the full window width N*Δ.

d must be finite and nonnegative; λ, lx and ly must be finite and positive. The input must be a nonempty one-based matrix. At zero distance, return an independent complex copy, bypassing the singular kernel (but still validating the grids and quadrature). A different output grid at zero distance is unsupported and raises an ArgumentError.

Scaled convolution uses a periodic Fourier interpolant of the sampled kernel, not its exact values at fractional displacements. Its kernel pitches are the larger input/output pitch on each axis. Both pitches must resolve the kernel; this is especially demanding for small distances and coarse output sampling. padding is a positive integer multiplying the kernel period in scaled mode. Increasing it moves the periodic boundary away from the required displacements but does not refine the kernel pitch. Check convergence with finer input and output sampling. The unscaled FFT-DI path ignores padding after validation.

[1] F. Shen and A. Wang, "Fast-Fourier-transform based numerical integration method for the Rayleigh-Sommerfeld diffraction formula," Applied Optics 45, 1102–1110 (2006), https://doi.org/10.1364/AO.45.001102, Eqs. (7)–(20).

[2] V. Nascov and P. C. Logofătu, "Fast computation algorithm for the Rayleigh-Sommerfeld diffraction formula using a type of scaled convolution," Applied Optics 48, 4310–4319 (2009), https://doi.org/10.1364/AO.48.004310.

Propagate a monochromatic light field with rayleighsommerfeld, preserving its wavelength and window centre. output_size is a pair of lengths with units; output_samples sets the output sample counts independently. By default the physical widths and counts are preserved. Input and output windows may be translated together without changing the result.

Physical windows

The light-field interfaces preserve gridcenter(field) for angular-spectrum, double-FFT Fresnel, single-FFT Fresnel and planar Fresnel–Kirchhoff propagation. The output window follows the input centre. Single-FFT Fresnel updates the physical widths using its sampling relation; the other planar methods preserve the widths. Single-FFT widths are positive for either propagation direction, so negative distances no longer reverse the output coordinate axes.

All three planar FFT methods accept finite signed distances, finite positive wavelengths and input widths, and nonempty one-based matrices. At zero distance they return an independent complex copy on the original grid. The matrix interfaces retain their original signatures and return conventions.

Finite-radius Fresnel–Kirchhoff propagation currently requires a zero-centred window. It rejects nonzero centres because the existing surface weights and geometry checks assume coordinates about the optical axis. Off-axis spherical propagation needs a separate numerical extension. Centred spherical windows continue to scale by 1 + d/radius.

FFT frequency grids

Angular-spectrum and double-FFT Fresnel propagation apply transfer functions in the native FFT frequency order. For an axis with N samples over a width L, this is fftfreq(N, N/L), including the zero-frequency sample for odd sizes. The spatial coordinates still follow the existing half-open window convention. Frequency bins and spatial sample positions have separate roles; an odd spatial window does not imply a half-bin displacement of the frequency grid.

These two propagators impose periodic boundaries on the input window. The angular spectrum transfer suppresses evanescent components for any nonzero distance, including backward propagation, rather than exponentially amplifying them. Consequently its forward/backward pair recovers only the propagating spectrum. The exact zero-distance identity retains all input components. Components exactly at the propagating cutoff are retained with zero longitudinal phase.

See AbstractFFTs' frequency and transform definitions.

Single-FFT Fresnel propagation

For nonzero distance, fresnel1 evaluates the discrete Fresnel integral

\[U_o(x_o,y_o) = \frac{e^{2\pi i d/\lambda}}{i\lambda d}\Delta x\Delta y \sum_{i,j} U_{i,j}\exp\left[\frac{i\pi}{\lambda d} \left((x_o-x_i)^2+(y_o-y_j)^2\right)\right].\]

The output has the same sample counts, with

\[\Delta x_o = \frac{\lambda |d|}{N_x\Delta x},\qquad \Delta y_o = \frac{\lambda |d|}{N_y\Delta y},\qquad L_{x,o}=N_x\Delta x_o,\quad L_{y,o}=N_y\Delta y_o.\]

Input and output coordinates both start at their window centre minus half the corresponding width. The implementation includes the input and output quadratic phases and the phase associated with those coordinate origins. This applies to odd sizes and singleton dimensions as well as even grids. Both windows can be translated by the same centre without changing the result in their local coordinates.

Positive distance uses a forward FFT; negative distance uses an unnormalised backward FFT with the corresponding phase and integral prefactor. Output widths remain positive in either case. The carrier phase is retained, so results can be compared as complex amplitudes, without adjusting an arbitrary constant phase. At zero distance the FFT sampling relation is bypassed and the input grid is kept.

The method preserves the discrete power sum(abs2, U) * Δx * Δy under its natural output sampling. Physical accuracy still requires the input window and spacing to resolve the field and quadratic phase; no automatic resampling or aliasing correction is performed.

using OpticalPropagation, Unitful

field = MonoLightField2D(ones(5, 4),
    wavelength=633u"nm", size=(0.1u"mm", 0.08u"mm"),
    center=(1u"mm", -2u"mm"))
forward = fresnel1(field, 2u"mm")
backward = fresnel1(forward, -2u"mm")
all(>(0u"m"), physicalsize(forward)), gridcenter(forward), isapprox(backward, field)
(true, (0.001 m, -0.002 m), true)

Fresnel–Kirchhoff propagation

fresnelkirchhoff evaluates a spatial zone-mask convolution using zero-padded FFTs. For normally incident illumination between parallel planes, the kernel retains the spherical propagation distance and Kirchhoff obliquity factor:

\[h(x,y) = \frac{e^{iks}}{2i\lambda s}\left(1+\frac{d}{s}\right), \qquad s=\sqrt{d^2+x^2+y^2}, \qquad k=\frac{2\pi}{\lambda}.\]

The input is zero outside its sampled aperture, and the output covers the same window. Sample coordinates follow the existing light-field convention: x[i] = -lx/2 + (i-1)*lx/n, and likewise for y. Sampling must resolve the phase of the kernel. This finite-aperture integral requires sufficient sampling as the distance approaches zero; the special case d == 0 returns a copy. It does not impose periodic boundaries.

using OpticalPropagation, Unitful

aperture = MonoLightField2D(ones(32, 24),
    wavelength=633u"nm", size=(0.1u"mm", 0.08u"mm"))
diffracted = fresnelkirchhoff(aperture, 20u"mm")
size(diffracted), diffracted.size
((32, 24), (0.0001 m, 8.0e-5 m))

For a spherical reference surface, set radius to the signed curvature radius of the incident wave. Positive values describe divergence; negative values describe convergence. Data contain the actual complex amplitude on the cap. The output cap is concentric and its projected widths scale by 1 + d/radius. Propagation to or through the common centre is unsupported.

spherical = fresnelkirchhoff(aperture, 20u"mm"; radius=100u"mm")
spherical.size
(0.00012 m, 9.6e-5 m)

The finite-radius mode implements the tangent-grid approximation motivated by Hudson's Eqs. (1)–(5), with the surface-area Jacobian applied to the input. It computes the zone mask from exact on-axis spherical geometry; translating this mask across the projected grid approximates rotation on the reference sphere. Use small caps relative to the radius. This grid approximation is not an exact integral between arbitrary spherical points.

For displacement radius $\rho=\sqrt{x^2+y^2}$, input radius $R$, and $c=\sqrt{1-\rho^2/R^2}$, the kernel uses

\[z_s=R(1-c), \qquad s=\sqrt{\rho^2+(d+z_s)^2}, \qquad \cos\chi=\frac{dc-z_s}{s}, \qquad h=\frac{e^{iks}}{2i\lambda s}(1+\cos\chi).\]

The quadrature weight at each input sample is $\Delta x\Delta y/c$ using that sample's distance from the optical axis. In the limit $|R|\to\infty$, these expressions reduce to the parallel-plane kernel above. The constant reference-wave factor in Hudson's Eq. (1) is already contained in the input amplitude; it is not multiplied into the result a second time.

Reference: Jerome A. Hudson, “Fresnel-Kirchhoff diffraction in optical systems: an approximate computational algorithm”, Applied Optics 23, 2292–2295 (1984). The implementation uses the derivation in the public publisher preview.

Rayleigh–Sommerfeld propagation

rayleighsommerfeld evaluates the first Rayleigh–Sommerfeld integral using Shen and Wang's FFT direct integration (FFT-DI). It convolves the finite input aperture with the full impulse response

\[h(x,y;d) = \frac{d\,e^{ikr}}{2\pi r^2}\left(\frac{1}{r}-ik\right), \qquad r=\sqrt{x^2+y^2+d^2},\qquad k=\frac{2\pi}{\lambda}.\]

The spherical phase, obliquity factor and near-field term are retained, without the Fresnel approximation. For equal grids, padding to at least (2Nx-1, 2Ny-1) prevents periodic wraparound in the retained output window; FFT lengths are rounded up to products of 2, 3 and 5 for efficiency. By default the output preserves the sample counts and physical widths. The wavelength and window centre are always preserved; both windows can be translated together. Distances must be finite and nonnegative. Zero distance returns a complex copy on the original grid; requesting a different output grid at zero distance raises an ArgumentError.

The default quadrature=:rectangle evaluates the Riemann sum with area Δx*Δy for every sample. It supports rectangular arrays, odd and even counts, and singleton dimensions. The optional quadrature=:simpson applies the tensor product of [1,4,2,…,4,1]/3 before convolution. Each dimension must then contain an odd number of at least three samples. Simpson's rule integrates between the first and last sample coordinates, a span of (N-1)*Δ; it does not add a sample at the excluded upper endpoint of the physical window of width N*Δ.

using OpticalPropagation, Unitful

aperture = MonoLightField2D(ones(65, 49),
    wavelength=633u"nm", size=(0.1u"mm", 0.08u"mm"))
diffracted = rayleighsommerfeld(aperture, 20u"mm")
simpson = rayleighsommerfeld(20u"mm"; quadrature=:simpson)(aperture)
size(diffracted), samplepitch(simpson), gridcenter(simpson)
((65, 49), (1.5384615384615385e-6 m, 1.63265306122449e-6 m), (0.0 m, 0.0 m))

Resolve both the input field and the oscillations of the kernel, especially for small distances or large transverse displacements. Zero padding prevents circular convolution but does not repair undersampling or an insufficient input aperture. Refine the sample pitch and check convergence when choosing a grid. Finite output windows may omit diffracted power, so a propagation pair is not generally an inverse and need not conserve the power measured inside that window.

Independent input and output sampling

Set output_size and output_samples to select the output window widths and sample counts independently, including different scale factors along x and y. Each option defaults to the input value. Widths have length units for a MonoLightField2D and are in metres for the matrix interface. The matrix interface returns output amplitudes. The light-field result also stores the selected widths. Coordinates follow the same half-open convention on both grids: x[i] = center_x - Lx/2 + (i-1)*Lx/Nx. Odd counts retain their half-sample origin offset. The output window follows the input centre.

zoomed = rayleighsommerfeld(aperture, 20u"mm";
    output_size=(0.06u"mm", 0.12u"mm"), output_samples=(81, 72))
physicalsize(zoomed), size(zoomed), samplepitch(zoomed)
((6.0e-5 m, 0.00012 m), (81, 72), (7.407407407407407e-7 m, 1.6666666666666667e-6 m))

A changed grid selects Nascov and Logofătu's scaled convolution, Eqs. (14)–(22), generalized to unequal counts and rectangular arrays. It retains this package's exp(+ikr) propagation convention and the full near-field term. For each axis, the kernel pitch and two scale factors are

\[\delta=\max(\Delta_i,\Delta_o),\qquad \alpha_i=\Delta_i/\delta,\qquad \alpha_o=\Delta_o/\delta.\]

The kernel is sampled on a centred, even grid with periods Mx and My that enclose every source-to-target displacement. The input's scaled Fourier transform is multiplied by the ordinary transform of the kernel, then transformed back at the output scale. With zero-based input indices $i,j$ and centred frequency indices $p,q$, this gives

\[\widehat U_{p,q}=\sum_{i,j} w_{i,j} U_{i,j} \exp\left[-2\pi i\left( \frac{\alpha_{i,x}(i-N_{i,x}/2)p}{M_x}+ \frac{\alpha_{i,y}(j-N_{i,y}/2)q}{M_y}\right)\right],\]

\[U_{o,a,b}=\frac{\Delta_{i,x}\Delta_{i,y}}{M_xM_y} \sum_{p,q} H_{p,q}\widehat U_{p,q} \exp\left[2\pi i\left( \frac{\alpha_{o,x}(a-N_{o,x}/2)p}{M_x}+ \frac{\alpha_{o,y}(b-N_{o,y}/2)q}{M_y}\right)\right].\]

Here $w$ contains the rectangle or Simpson input weights, and $H$ is the DFT of the sampled kernel $h(s\delta_x,t\delta_y)$. The area factor uses the input pitches. The scaled transforms use the chirp convolution from Appendix A, with zero-padded FFTs; no dense transform matrices or direct source-to-target sums are constructed. With comparable counts on both axes, the work scales as $O(M_xM_y\log(M_xM_y))$. Simpson restrictions apply to the input counts only; the output counts may be even or odd.

Unlike the equal-grid FFT-DI path, scaled convolution evaluates a periodic Fourier interpolant of the kernel at fractional displacements. It therefore has an interpolation error in addition to input quadrature error. Resolve the kernel on both grids: a fine input grid alone does not compensate for a coarse output grid because the larger pitch determines $\delta$. For each axis, the phase sampling condition from Section 4 is

\[\frac{\delta X}{\lambda\sqrt{d^2+X^2}}<\frac12,\qquad X=M\delta/2.\]

Also resolve the near-field amplitude variations on the scale of d. These are sampling guidelines; verify convergence by refining input and output pitches. Increasing the positive integer padding multiplies the kernel periods, moving the periodic boundary away from the needed displacements. It increases memory and work and does not refine the kernel pitch; it cannot correct undersampling. For example, add padding=2 to compare with twice the default period on each axis. For an unchanged output grid, the original Shen–Wang FFT-DI path is used and padding has no effect after validation.
